# Demand Forecasting with XGBoost

A first machine learning project exploring retail demand and predicting demand from price, discount, inventory, promotion, competitor pricing, and category.

## Project files

- `notebooks/analysis.ipynb` — data checks, feature exploration, and visualizations.
- `notebooks/machine_learning.ipynb` — feature preparation, XGBoost tuning, and evaluation.
- `data/raw/demand_forecasting.csv` — local dataset. Git ignores this file until its redistribution terms are confirmed.
- `app.py` — Streamlit interface for one-row demand predictions.
- `artifacts/` — local model and encoder files generated by the training notebook. Git ignores these generated files.

## Dataset

The project folder did not include source notes. The dataset appears to match the 76,000-row, 16-column dataset described in [HiraAli01/demand-forecasting-dataset](https://github.com/HiraAli01/demand-forecasting-dataset), which points to [ASOS-dataset-for-machine-learning](https://github.com/HiraAli01/ASOS-dataset-for-machine-learning) for the CSV. This source match is based on the file name, shape, and columns; it is not independently confirmed.

The reposting repository provides no dataset license, and the upstream license is unverified. Keep the CSV out of public commits unless you confirm redistribution is allowed. To run locally, place the permitted dataset at `data/raw/demand_forecasting.csv`.

## Results

The notebook records a holdout RMSE of **36.08 demand units**. It uses a random train/test split, so this score does not measure performance on future dates. A time-based split would be better for forecasting.

## Run locally

Use Python 3.10 or newer.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Place the dataset at `data/raw/demand_forecasting.csv`. Open and run every cell in `notebooks/machine_learning.ipynb` to train and save model files under `artifacts/`. Then start the app from the project folder:

```powershell
streamlit run app.py
```

The app shows a setup message until valid model files exist.
